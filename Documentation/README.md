# Dice Brawler — Design Documentation

This folder presents selected game design documentation for **Dice Brawler**, a first-person, dark-fantasy dice-battling roguelite set in a tavern.

> **Development note:** These documents describe the intended design, including planned features and concepts under development. They are **not** a complete list of implemented features. Specific implementation status should be verified against gameplay footage or the current build.

## Documents

- [Game Design Overview](GameDesign.md) — premise, player experience, core loop and progression
- [Combat System](CombatSystem.md) — turn structure, dice placement and scoring
- [Enemy Design](EnemyDesign.md) — enemy archetypes and rule-breaking encounters
- [Dice, Drinks & Items](ItemsAndDrinks.md) — tools that modify the standard rules

## Design focus

The central design challenge is making a simple, readable dice contest produce meaningful decisions through **hidden rolls, alternating placement, limited resources and opponents that bend the rules**.
